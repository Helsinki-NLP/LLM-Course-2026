# Week 7

## Lecture overview

The final week connects the full model life cycle: architecture, pretraining,
post-training, inference, evaluation, retrieval and agents. The sessions also
leave room for special topics, questions and project support.

## Project work

There is no new technical lab assignment. Use the week to:

1. organize the evidence produced in earlier labs;
2. rerun missing or inconsistent comparisons;
3. check that every reported result can be reproduced from the repository;
4. write one report section for each main course topic; and
5. finish with a synthesis explaining how the components interact and what
   you learned from the complete system.

Email the final report as a PDF and the code as a ZIP archive to
`aarne.talman@helsinki.fi` by 31 December 2026.
