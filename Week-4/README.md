# Week 4

## Lecture overview

The lecture examines what model scores do and do not tell us. Topics include
task-specific metrics, benchmark design, data contamination, model-based
evaluation, uncertainty, error analysis and evaluation across languages and
cultures.

## Lab 4 assignment

Evaluate the model variants produced or selected in earlier weeks:

1. Define the behaviour or capability the evaluation is intended to measure.
2. Apply the same task data and scoring protocol to the relevant baseline,
   fine-tuned and served models.
3. Inspect individual errors rather than relying only on an aggregate score.
4. Check for contamination, language coverage and other limitations that
   affect interpretation.
5. Save a reusable evaluation script for the RAG and agent systems built in
   weeks 5 and 6.
